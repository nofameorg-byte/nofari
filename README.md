# NOFARI Intelligence Platform

NOFARI is a new intelligence platform. Sprint 001 establishes the permanent project foundation
without shipping product features, mock dashboards, fake metrics, or simulated AI behavior.

## Stack

- Next.js 16 App Router
- TypeScript
- Tailwind CSS 4
- Prisma 7
- PostgreSQL

## Getting Started

Install dependencies:

```bash
npm install
```

Copy the environment example and fill in local values:

```bash
cp .env.example .env
```

Run the development server:

```bash
npm run dev
```

## Verification

```bash
npm run lint
npm run typecheck
npm run build
```
